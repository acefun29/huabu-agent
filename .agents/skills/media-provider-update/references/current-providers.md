## Freshness gaps noticed in this snapshot

These are prompts for a future updater to re-check, not changes made by this reference:

- OpenAI's current image documentation lists GPT-Image-2.6 models; the checked-in catalog stops at GPT-Image-2.5 Flare. Its image API reference also reports `gpt-image-1` shut down on 2026-10-23 while this catalog still retains it as deprecated. Confirm exact live model availability and adapter parameters before changing the catalog.
- Volcengine's current model list and image-generation guide show Seedream 5.5 (`doubao-seedream-5-5-261028`); the checked-in catalog stops at Seedream 5.0 Pro/Flash/Lite. Verify exact model ID, supported parameters, endpoint and rollout status before adding it.
- Tencent's TokenHub catalog and Bearer key system are distinct from the direct CAM-signed Hunyuan adapter. The adapter covers Hy Image 3.5, WAND-Vega images, Kling Video V4 and PixVerse V6/C1; other model families require their own protocol mapping. Do not repurpose `TENCENT_KEY` for TokenHub.
- MiniMax's official docs expose speech models, but the checked-in media adapter declares only image/video generation. A future audio catalog entry needs a real audio-generation adapter path and support for Huabu's `audio` kind first.
- Kling's direct API uses a distinct Access Key / Secret Key JWT scheme and is not yet integrated. The current vendor documentation must be accessible and its signing and task contracts verified before enabling direct access; TokenHub's Kling adapter uses a separate TokenHub key and API.
